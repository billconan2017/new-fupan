## 旧策略实际包含什么

1. market_emotion_analyzer → intraday_selector_v2：前一日涨停数与涨停股中开板比例决定freeze/cold/warm/hot等状态。冻结阈值包含涨停数小于50。其开板比例不是包含全部未回封股票的完整炸板率。
2. intraday_selector_v2：博主方向、盘中主线、防守轮动池按市场状态合并；time_strength_scorer使用昨日首次封板时间、开板次数，早封加分、午后首封降权。
3. app.py的独立路径：09:31开盘承接、09:40修复、板块/前排/资金联动。945/1000字段已被改作09:31/09:40语义，不能按字段名推断信号时间。
4. build_blogger_view_library → build_blogger_stock_picks：关键词规则整理文章，方向映射行业，再结合成交额、换手、资金等选股。它不是已经证明有效的AI预测模型。

不同引擎并存，不能推断所有输出都受同一情绪闸门约束。前次简化竞价回溯不是这些旧策略的回测。新版尚未完整迁移这些规则，页面明确标记这一点。

迁移不能照搬的缺陷：均价缺失回退最新价会使aboveAvg自然通过；上下文支持可由“板块/核心/竞价”等文字触发；文章日期可来自文件名/mtime，无法证明当时已知；历史确认后的入场不能回退到确认前开盘价。必须分别用真实时点和字段证据替代。
