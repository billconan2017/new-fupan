# 最近五个交易日早盘回溯

入口：8899首页 → 次日备选与研究 → 近五日回溯。

运行：先在进程环境设置 LIANGMAI_TOKEN，执行 `.venv/bin/python scripts/replay_recent.py`。脚本自动选择当前上海日期之前的5个交易日，以最后一个完整交易日作为后续行情截止日。令牌不进入业务参数、缓存键、报告或源码。

规则在看收益之前固定为 morning-replay-v1：普通沪深主板（00/60开头）且当日竞价名称无ST/退；前日涨停池、强势池或龙虎榜有交集；竞价涨幅1%—8%；复用现有竞价评分，至少60分，按规则分、抢筹成交额和代码排序，最多3只。未触发不补选。历史龙虎榜按endDate核对；不带日期的池明确标注依赖请求参数，不能说全部源日期独立验证。

09:35结束的首根五分钟K线必须收阳。模拟09:40入场，参考价取09:45结束K线的开盘价。这一时间映射为数据解释假设，尚未逐笔核验。检查当日涨跌停价、停牌、量和OHLC，触及价格限制或单一价格条不假定买入。候选阶段不使用当天日线收盘或未来结果。

分别在买入后的第1、2、3交易日收盘参考价模拟退出，跨过休市。未来日期标记未到期；缺少区间日线、前收盘价连续性、退出跌停价的单列待核验；触及跌停或单一价格的退出单列受阻，不虚构已实现收益。没有把不完整仓位当成0收益或自动平仓。

每笔独立预算10000元、100股整数倍。费用假设：双向佣金0.03%且最低5元、双向过户费0.001%、卖出印花税0.05%、双向滑点各0.1%。滑点作为成本压力从参考价测算中扣除，不声称历史区间外价格实际成交。佣金和滑点为研究假设，不代表用户账户费率。净变化以实际模拟投入（含买入成本）为分母，剩余未使用现金不计入此分母。

费用参考：[税务总局证券印花税减半公告](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5211343/content.html)、[上海市委金融办转载中国结算过户费调整](https://jrj.sh.gov.cn/SCDT197/20220429/f715759a877b4158812eb6df70ccb49e.html)。

输出：`data/research/recent_replay.json`及`data/research/recent_evidence/`（全部被Git忽略）。缓存保存参数对应的原始证据，复跑不会改用新赢家或丢弃失败候选。界面分别显示每个持有期的已评估、未知、受阻及未到期数量，并额外给出三种持有期都可计算的共同样本结果。

这是固定规则的探索性重建，不是当时发出的推荐，不是账户收益曲线，也不是逐笔撮合回测。规则尚未通过独立样本外检验。只有一笔已评估样本，不得宣称某个时段或持有期稳定盈利。
