# 短线工作流与数据就绪检查（V4.2）

8899首页新增“今日工作流”，四个入口：盘后备选、约9:26竞价确认、9:30—10:00早盘观察、T+1计划复核。原标的、研究、观察计划、复盘及接口证据仍可访问。调整窄屏导航、表格换行、控件对比度、加载状态，研究页读取过程中不再闪现“没有数据”。

`GET /api/workbench/readiness?day=YYYY-MM-DD` 只读取本地证据。7项检查按实际用途评估，而不是按接口200响应：

- 交易日历需含所选日、前日及未来两个交易日。
- A股行情先与股票列表匹配，再检查价格、开盘价、涨幅、成交额和量比；源时间独立于采集时间。失败降级明确显示本地旧行情。
- 竞价需要日期匹配、抢筹金额/涨幅/委托字段齐全，但50条排行不冒充全市场或9:25前信号。
- 盘后需涨停、强势、炸板、龙虎榜；收集时间必须在信号日17:10之后，上午缓存不会因为时间过了17:10自动变为正式盘后证据。
- 早盘5分钟线按每只股票检查09:35至10:00六根、OHLC、成交量、停牌字段。
- 涨跌停价必须有与所选日期匹配的上下限。非空但旧日期也判缺失。
- 趋势日线检查截至前日的65个连续交易日。

`POST /api/workbench/collect` 增加 `stage=execution`，接受1—20个六位股票代码，采集上述早盘5分钟线及所选日价格限制。首页默认最多补采5只盘后候选；个股抽屉也可单独补采。返回数据保存在原wb_evidence中，用minute_5:代码和limit_prices:代码区分，前复权趋势日线不被覆盖。实际展示范围是已采样股票，不能说已全市场补齐。

修复采集任务动态总数，前日股池补采计入进度，跨年盘前定位可读取前年日历。页面保存活动任务ID，刷新后继续跟踪；存储不可用时仍能继续当前采集。

实测2026-09-17：5只候选的6根早盘分钟线齐全，当日涨跌停价全部返回空。全市场快照新请求失败后保留11:31:30同日本地记录，仍标过期，不宣称实时。日线仅已测21只中的20只通过65日覆盖，不是全市场覆盖。

结论：够做带缺口提示的观察与研究，尚不够完整实盘及可靠回测。当前没有9:25前实时竞价确认、后台连续归档、真实券商委托/成交反馈、充分的样本外组合验证。页面60秒快照轮询只在页面打开且勾选时生效，不能称为无人值守采集。
