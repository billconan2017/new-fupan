# 自动观察与模拟复核

从部署后真实冻结的信号开始，不把回溯的赢家加入真实观察历史。不接券商，不自动下单。

## 固定规则

- 每个交易日17:30以后首轮有效盘后采集完成后，冻结前日热点全名单和最多5只精选。精选要求普通沪深主板、非ST/退、涨停/强势/龙虎榜至少两类交集、成交额≥1亿元、同一行业最多2只。
- 次日09:26采集完成后的09:30之前，按已有固定竞价规则（涨幅1%–8%、规则分≥60）分别从前日热点和前晚精选中选前三名，形成两组观察记录。规则版本和费用假设冻结保存。
- 没有前晚真实冻结记录、竞价采集失败或晚于09:30，不补造早盘信号。没有合格股票保持空名单。
- 自动记录同步进“我的观察计划”，两组策略的逐笔结果在同页“自动观察”分开统计。
- 入场模拟沿用 morning-replay-v1：09:35首根五分钟K线收阳，参考09:45结束K线开盘价模拟09:40入场。需核验涨跌停价、成交量、停牌。无法核验记未知，不算成功或失败。
- 盘后自动核验最近10个交易日的已冻结竞价记录。每笔按1万元、100股整数倍、既有固定佣金/税费/滑点模型模拟；持有1/2/3个交易日分别按收盘参考价退出。T+1、除权异常、停牌、跌停无法确认卖出均单列。没有实际成交证明。

17:30后第一批的名单不会被20:30或22:00数据覆盖。这保证信号不可回写；晚间新增消息暂不自动替换原名单。关闭电脑或停服务会错过窗口。

## 如何看成功率

盈利比例只除以有完整证据、可评估退出的笔数；同时展示总信号、未触发、未到期、待核验数量，避免分母被隐去。持有期比较另列三种持有期都完成的共同样本。两个策略可能含相同股票，不能合并当成独立样本。不是资金组合回测，没有证明持续盈利。

2026-09-17复算9月10/11/14/15/16日五个交易日的旧采集证据：14个候选，12个未触发、1个未知、1个模拟入场。唯一可评估T+1净变化-18.605%；提高评分门槛仍保留这笔，竞价涨幅≤5%过滤后没有可评估样本。不能从这些结果得出更高胜率或最佳持有天数。详细结果在“次日备选与研究”的最近五日回溯内。

## 日线

首页分时下方直接显示前复权日K线、MA5/MA10/MA20和成交量，支持60/100日视图。标的详情中的日线默认展开。沿用截至前一交易日的历史接口，不把当日未收盘价格混入趋势评分；均线按返回的有效日线计算，缺失需通过数据覆盖检查。

## 表与调度

- wb_paper_batches：唯一日期/阶段，记录空名单、盘后范围及竞价冻结证据。
- wb_paper_signals：唯一日期/策略/股票；入选依据不可覆盖，模拟评估结果可更新。
- wb_plans：用户可见观察记录，重复不覆盖手动记录。
- 原systemd定时器增加paper阶段，无需Hermes。collect中的paper分支受既有采集互斥约束。
