# 旧策略回溯、交易档案与图表（2026-09-17）

主页新增真实交易档案、选股策略、历史回溯快捷入口。真实台账、历史重建和每日纸面观察分别展示。

## 历史重建

运行 `.venv/bin/python scripts/replay_legacy.py`，使用 `LEGACY_ROOT` 指向旧工程，默认本机旧工程路径。只读主库、备份库、冷库，并使用此前缓存的量脉2026交易日历；不请求远端，不导入旧Flask应用，不执行旧定时任务。

`legacy_rules/stage.py` 保存旧 app.py 的 `_num`、`_intraday_prev_risks` 和 `_intraday_stage_status`，含原文件SHA256。仅将分钟读取函数改为显式注入。保留承接、回撤、强修复与追高限制阈值；不是完整旧策略引擎。

研究的输入修正：只使用09:30后的分钟记录，要求目标分钟存在，均价缺失拒绝，不沿用旧代码的“均价缺失用最新价”逻辑。确认后取下一分钟价格作参考，退出按交易日历T+1/3/5，三种持有期共用完整样本。主库优先于备份、冷库；不使用当前涨幅回填历史候选。种子池可能事后回填，尚未证明其当时可获得；未证明复权一致性、涨跌停可成交与实际费用，因此报告标为价格路径研究，不是策略收益。

本次审计10,893条记录、76日期，4,829条去重种子，仅594条有早盘分钟。09:31规则通过并有完整路径70条，09:40为51条，阶段间可能重复。T+1平均价格变化分别-0.518%、-1.810%。不可据此选出最佳持有期、宣称持续盈利或替换实时规则。新版完整竞价评分还需要抢筹委托额，旧字段并不等价，没有伪造新旧全策略同样本对比。

完整结果保存在忽略提交的 `data/research/legacy_replay.json`，接口 `/api/workbench/legacy-replay`。记录时间审计显示事后回填、晚于入场窗口的记录，观察状态并不等于买入。

## 用户交易档案

以SQLite backup保存旧 `api/data/portfolio.db` 一致性快照至用户目录 `.local/share/guanmai/legacy/portfolio.db`，权限0600。运行时只读此独立快照，也可由 `LEGACY_PORTFOLIO_DB` 指定。原库不变，台账不写入Git，不写入模拟计划。

展示17条持仓档案、31笔买卖流水。原始状态仅是旧库最后记录，不代表当前券商持仓；时间字段可能是录入时间。对比买卖净数量与持仓表未平仓数量，差异公开标记，不自动改账。已填利润只作原始数据汇总，未核验费用。

## 图表

使用项目既有ECharts依赖：日K线、MA5/10/20、成交量；分时价格线/5分钟K线切换，昨收参考线。滚轮缩放、拖动平移、滑块选区、十字线，以及20/60/100日、10点前/全天快捷范围。午休不画交易点，缺失采样不补直线；股票或日期变化重置范围。

按[ECharts容器生命周期文档](https://echarts.apache.org/handbook/en/concepts/chart-size/)使用ResizeObserver与销毁处理，适配抽屉、折叠区域与窗口尺寸变化。
