# 观脉 V4：重新开发的实盘研究与复盘工作台

2026-09-17。本轮重写默认前端与工作台业务 API，复用已校验的量脉网关客户端；不是给旧 cockpit 页面换皮。新前端不再加载旧页面路由及设计样式。原页面源码保留作参考。

官方核对：[量脉功能介绍](https://liangmai.pro/#features)、[接口文档](https://liangmai.pro/docs#description/introduction)。文档内嵌 OpenAPI 的 operationId、参数、字段与实测响应交叉检查。官方称 255 个接口；本轮按业务需要实测，不把接口目录等同于全量可用性证明。

## 使用流程

- 盘前：交易日历确定前一交易日，前日股池作背景；当天竞价使用 qczf 抢筹涨幅、qccje 抢筹成交额、qcwtje 抢筹委托金额。该榜单约 9:26 后可用；无可信价格时不填价格。增强板块竞价使用 bkName/jjzf。当前人气和盘中涨停结果不混入盘前。
- 盘中：全市场快照与 A 股证券列表关联后筛选，按成交额、量比、涨幅、股票名称、股池和已知行业过滤。可选“盘中60秒更新”，仅页面开启、今天、官方交易日且连续交易时段检查采集快照；默认关闭。行业当前来自股池，不是完整行业目录。
- 短线：成交额/5亿（上限30分）、量比/3（上限25分）、涨幅/5%（上限25分）、不低于开盘价20分。前三项截断至0—权重上限。
- 盘前短线：抢筹成交额/5000万（上限40分）、抢筹涨幅/5%（上限30分）、抢筹委托额/1亿（上限30分）。字段不全不评分，不用剩余字段重分配权重。
- 趋势：MA20>MA60 为30分；价格>MA20为25分；MA20较五日前上升为25分；价格突破此前20日最高价为20分。前复权日线截至前一交易日，至少65条，核对已载入官方交易日是否缺失。不使用当天未收盘日线。盘前趋势参考价为前日收盘。
- 个股详情：前复权K线、因子分值、公式输入、源时间、风险标签。指数/基金不作为股票候选；ST/退市名称默认过滤。用户可保存观察理由。
- 观察计划：按日期、股票、模式、阶段冻结依据、价格、因子版本与保存时间，重复保存不覆盖。结果对照只计算源时间晚于原引用价的行情，不含费用，不是账户收益。历史补录记录会留下真实保存时间，不能当作当时已生成的策略信号。
- 盘后：独立采集股池、情绪、龙虎榜，显示缺项；查看观察结果、按日记录笔记并导出摘要。笔记当前在浏览器 localStorage，计划保存在 PostgreSQL。

规则是可解释的研究筛选器，未声明收益预测能力。资金流/人气/行业只作来源明确的旁证；不混合多个数据供应商的单位。当前无券商下单能力。

## 数据架构与预算

`wb_evidence`：按接口/日期保存数据、状态、条数与检查时间。只有 ready/local 可以参与计算。local 明确表示上游失败后使用同日期本地证据；仍按原行情源时间判断时效。

`wb_jobs`：持久化采集进度和各接口结果，通过 PostgreSQL advisory lock 控制任务准入。请求处理立即返回任务ID；前端展示进度。单次日线补采最多20只，单接口超时/总预算沿用统一客户端。服务重启把未完成任务标记失败。要求单 worker；不用于多进程后台队列部署。

`wb_plans`：不可覆盖的观察依据。新工作台读请求不触发外部接口，只有采集任务消耗额度。全部数据与凭证留在本机数据库/环境，不提交Git。

日线官方更新时段为15:30开始、约17:10完成；竞价约9:26后可用；全市场快照每分钟最多1次。盘中刷新只采快照，其余阶段证据需按需同步，页面的数据证据表显示检查时间。

## 8899 部署与兼容

本机已部署：新后端由 `guanmai-workbench.service` 管理，监听127.0.0.1:19009；使用独立 PostgreSQL 库与本机私有socket，原数据库不覆盖。

原 `local-stock-review.service` 保留8899入口，通过 `scripts/flask_workbench_bridge.py` 提供新首页与新资源，仅代理 `/api/workbench/*` 到新后端，原API及旧采集任务保持可达。`/?legacy=1` 进入旧首页。新根页面也可直接在19009访问。

桥接通用用法：在原Flask应用创建后调用 `register_workbench(app, 新版frontend/dist绝对路径)`。本机只在旧run.py增加这次注册，旧文件已备份为 `run.py.before-guanmai-v4`。需要回退时恢复该备份并重启原服务，然后停止新服务；无须回退/删除数据库。不要对旧库执行本项目迁移。

新项目独立部署：配置私有 `.env`，安装依赖，`alembic upgrade head`，前端 `npm ci && npm run build`，单worker启动FastAPI。默认独立库；新增工作台不依赖旧Flask。

## 验证与边界

隔离数据库测试、生产构建、8899浏览器验收均已执行。测试覆盖：未来K线排除、交易日缺口、缺因子不评分、竞价不读当天连板背景、冻结计划不覆盖、行情源时间先后、历史日禁止采实时快照、同日期本地降级、错误任务恢复。

这是可运行的新研究工作台，不代表原系统的所有财务、分钟级回测、博主策略和实盘执行模块已经重写完成。未一次性探测全部255接口，也未重拉全市场历史；趋势按选中范围分批补齐。未实现券商成交、自动买卖或收益保证。冷热库全量整合、统一复权/单位、完整行业目录和严格逐时点回测仍需独立验收。
