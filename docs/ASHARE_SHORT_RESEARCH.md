# A股短线与超短研究（2026-09-17）

目标流程：盘后次日备选 → 次日约9:26竞价结果核对 → 9:30—10:00开盘后观察 → 买入后的下一交易日起退出。10点截止是用户的策略约束，不是已被证实的市场规律。趋势模式保留作辅助。

## 已落地

8899 首页「次日备选与研究」合并同日涨停池、强势池与龙虎榜，按证据交集数、行业聚集数和成交额排序。历史无全市场快照时也能形成观察候选。龙虎榜多条原因记录不重复累加资金；没有把上榜当作买入信号。

展示信号日、计划买入日、最早卖出日。日期使用交易日历，跳过休市。当天17:10前标记临时结果；四项证据或日历未齐时不允许冻结正式盘后计划。历史日期冻结会标记为事后重建，保存完整来源状态、规则版本及T+1窗口，没有生成真实成交。

盘前采集补齐前一交易日的强势池和龙虎榜；竞价候选显示前日热点证据，不用今日盘后龙虎榜解释早盘行为。9:26返回的结果不能假设按9:25撮合价买入。10点后页面转为跟踪提示；系统没有自动下单。

## 接口审计

`scripts/audit_liangmai.py --spec <官方OpenAPI JSON> --day 2026-09-16` 用已公布参数示例逐接口做一个样本请求，限速60次/分钟、最多3个并发、单次尝试。`--resume` 保留已有成功和空结果，重查失败或未测项。季度缺省使用2026年中报，报告保留实际参数。凭证仅取 LIANGMAI_TOKEN；不写入输出。

255接口目录已全量做样本请求。报告在被Git忽略的 `data/research/interface_audit.json`，经只读路由提供给界面；只保存状态和结构摘要。非空对象的键数不是业务行数。一次成功不表示历史字段齐全、全市场覆盖或任意参数都能成功。

重要修复：历史逐笔 `market_tick_history` 和 `market_tick_bj_history` 文档摘要写ISO日期，参数示例实际要求YYYYMMDD。实测ISO报500，紧凑格式成功；客户端现在接收两种格式，只对这两个端点统一转成YYYYMMDD。

## 历史研究的实际边界

`scripts/study_history.py` 在6个预先固定日期，从对应日期强势池选择普通沪深主板成交额前5名，研究次日开盘参考价到买入后第1/2/3/5/10交易日收盘参考价的变化。使用不复权价格。要求11个后续交易日完整、OHLC有效、成交量正、停牌字段为0，并剔除单一价格日和前收盘价断裂。各持有期共享同一批样本。

本次30个样本，29个路径可计算，1个因前收盘价断裂排除。**这不是原策略回测，不是历史已发推荐的业绩，也不是可成交收益。** 历史池缺少响应内日期，仍依赖上游执行请求日期；共同完整样本筛选还会产生事后可用性偏差。未计成本、未验证成交价、未模拟账户资金、未开展独立样本外检验，不能选出“最佳持有期”或声称持续盈利。页面列出逐条路径和缺口，不计算虚假的年化或账户收益。

针对10点前假设，另验证了000001在2026-06-16、08-17、09-16的5分钟历史，三个日期都返回09:35至10:00的6根K线。这仅确认样本可获取，不能证明全部股票、分钟覆盖和策略有效性。完整早盘回测仍需冻结信号时点、按K线结束时点使用信息、手续费与滑点、涨跌停及成交约束、样本外区间和组合资金模型。

持有1日的定义是买入后下一交易日退出，不是当日买卖。若盘后D日产生信号，D+1买入，最早D+2卖出。源依据：[量脉文档](https://liangmai.pro/docs)、[上交所2026年交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)。
